# 농업 R&D 규정 검색

국가연구개발혁신법·시행령·시행규칙, 국가연구개발사업 연구개발비 사용 기준(범부처)과
농촌진흥청 운영규정·연구개발비 관리지침·운영 매뉴얼(농진청) 13종을 조문 단위로 검색하는 웹앱입니다.
휴대폰에서는 "홈 화면에 추가"로 앱처럼 설치할 수 있고, 한 번 열면 오프라인에서도 열립니다.

## 파일
| 파일 | 내용 |
|---|---|
| index.html | 웹앱 화면 |
| data.json | 규정 본문(조문·항목 단위) |
| status.json | 자동 점검 대상 8종의 현행 번호, 마지막 확인일, 개정 이력 |
| manifest.webmanifest, sw.js, icon-*.png | 앱 설치·오프라인용 |
| scripts/update_laws.py | 국가법령정보센터 대조·반영 스크립트 |
| .github/workflows/daily-update.yml | 매일 00:00(KST) 점검 후 배포 |

## 처음 한 번 설정
1. 이 폴더 전체를 GitHub 저장소(예: `rnd-rules`)의 main 브랜치에 올립니다. `.github` 폴더도 함께 올려야 합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 바꿉니다.
3. (권장) open.law.go.kr에서 Open API 인증키(OC)를 신청한 뒤, **Settings → Secrets and variables → Actions → New repository secret**에 이름 `LAW_OC`, 값에 인증키를 넣습니다. 없으면 공개 테스트 키로 조회합니다.
4. **Actions** 탭에서 "규정 개정 점검 및 사이트 배포"를 한 번 수동 실행(Run workflow)하면 주소가 `https://<계정>.github.io/<저장소>/`로 열립니다.

## 매일 자동 점검
- 매일 00:00(KST)에 법령·고시·훈령 8종을 국가법령정보센터 현행본과 대조합니다.
- 개정이 있으면 새 본문으로 data.json을 바꾸고 사이트를 다시 배포합니다. 첫 화면에 "최근 개정 반영"이 45일간 표시됩니다.
- 조문 수가 크게 줄거나 순서가 맞지 않으면 자동 반영을 보류하고 워크플로를 실패로 표시합니다(저장소 소유자에게 GitHub 알림 메일이 갑니다). 이때는 개정 원문으로 수동 반영해야 합니다.
- 농진청 운영 매뉴얼·서식, 연구개발비 관리지침, 성과지표 정의서, 생명자원 기탁기관 목록은 국가법령정보센터에 없어 자동 점검 대상이 아닙니다. 개정 파일이 나오면 data.json을 다시 만들어 올려야 합니다.
- GitHub는 60일 동안 저장소 활동이 없으면 예약 실행을 멈춥니다. 매일 점검 기록이 커밋되므로 보통은 멈추지 않지만, 멈췄다면 Actions 탭에서 다시 켜면 됩니다.
